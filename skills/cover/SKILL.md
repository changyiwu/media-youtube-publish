# 封面

只做「底圖 → 封面」：裁切、（選用）疊字、輸出。**不生圖**，底圖從哪裡來由各專案的文件規定。

原始檔在 `agents/media-youtube-publish/skills/cover/`，用 `skill-sync` 裝到全域給各媒體專案共用；要改就改原始檔再同步，不要改全域副本。

## 兩條路線怎麼選

| | **A 後製疊字（預設）** | **B draw 直接生字** |
|---|---|---|
| 適用 | 一般集數、要維持系列一致的版位與字型 | 特別企劃、需要金屬／霓虹／立體／筆刷等字效，或字要跟畫面互動（被人物擋住一角、融進場景） |
| 底圖 | 不寫字，文字那一角留乾淨 | 生圖時連字一起畫 |
| 字的正確性 | 保證正確 | 可能錯字，**必過錯字檢查關卡** |
| `cover.py` | `--text` | `--no-text`（只裁切輸出） |

拿不定就走 A。專案文件（例如頻道風格指南）沒開放 B 時，只能走 A。

## 步驟

1. **選底圖**（照專案規定；沒有規定時用下列原則）：
   - 用**沒有燒字幕的乾淨畫面**：首幀、渲染圖、關掉字幕層輸出的那一格、插畫原圖。成片截圖通常帶字幕，最後才考慮。
   - 單一焦點、主體清楚、文字那一側有留白或背景單純。
   - 不要用 AI 生圖冒充作品畫面（例如 3D 渲染作品）。
   - 走 B：照下方〈路線 B：生字規則〉生圖。
2. **確認字型**（只有 A 需要）：依序找 `--font` → 環境變數 `COVER_FONT` → `~/.config/cover/fonts/` 裡第一個 `.otf`／`.ttf`。
   只用 **OFL 等可公開使用授權**的字型（源石黑體、Noto Sans TC）。都找不到就停下來問使用者，**不要自動下載**。
3. **確認前置**：`python -c "import PIL"` 要成功（沒有就請使用者同意後 `python -m pip install pillow`）；來源是影片時另需 `ffmpeg`。
4. **執行**（同目錄的 `cover.py`；`--text` 與 `--no-text` 必須二選一，都沒給或都給會報錯）：

   ```powershell
   # A 後製疊字
   python "<本技能目錄>/cover.py" "<底圖或影片>" `
     --text "<主標，6 字內>" --sub "<小標，選用>" `
     --font "<字型檔>" --corner bl --focus 0.5,0.4 `
     --formats yt,reel,post --outdir "<作品資料夾>"

   # B 圖裡已有字，只裁切輸出
   python "<本技能目錄>/cover.py" "<已含字的圖>" --no-text `
     --focus 0.5,0.5 --formats yt --outdir "<作品資料夾>"
   ```

   | 參數 | 說明 |
   |---|---|
   | `--text`／`--no-text` | 二選一：疊字，或只裁切（B） |
   | `--at 秒數` | 來源是影片時取哪一格 |
   | `--focus x,y` | 裁切焦點（0–1），放在人臉或主體上；B 要確保字沒被裁掉 |
   | `--corner tl/tr/bl/br` | （A）橫式封面文字放哪個角（左上／右上／左下／右下）；選不會擋到臉或主體的角。人物在畫面中上方時通常選左下或右下 |
   | `--formats` | `yt`（1280×720）、`reel`（1080×1920）、`post`（1080×1350） |
   | `--fill`／`--accent`／`--stroke` | （A）主標、小標、描邊顏色，預設白／金 `#FFC53D`／近黑 |
   | `--shade 0–255` | （A）文字所在角落的暗角強度，預設 150；底圖本來就暗可調低或設 0。`--no-text` 不加暗角 |

   輸出 `cover.png`、`cover_9x16.png`、`cover_4x5.png`，放在作品資料夾（與 `發布資訊.md` 同層）。
   YouTube 版超過 2MB 會自動改存 JPEG。橫式底圖做直式時，會改成「模糊背景＋整張圖放下方、字在上方」，避免把臉放大裁掉或被字蓋住；
   B 的橫圖做直式時同樣整張放下方，圖裡的字不會被裁。
5. **親自開圖檢查**每一張：字有沒有壓到臉或主體、YouTube 版右下角（影片長度標籤）是否乾淨、
   Reels 版的字是否落在上方 20% 以下與下方 25% 以上。不滿意就調 `--corner`、`--focus`、`--shade` 或換底圖重跑。
   走 B 還要過〈🛑 錯字檢查關卡〉。
6. 把封面路徑寫回 `發布資訊.md` 的〈作品資料〉封面欄；走 B 時，AI 揭露要註明「封面文字由 AI 生成」。

## 路線 B：生字規則

- **主標 6 字內，越少越好**；英文、數字比中文穩，筆畫多的中文字最容易出錯。小標能省就省。
- Prompt 寫出**逐字原文**並加引號，再加「畫面中只出現這些文字，不要其他任何字、標誌或浮水印」；字效（材質、光澤、描邊、立體角度、配色）另外描述。
- **字放在安全區**：draw 橫圖 1536×1024 裁成 16:9 會上下各少約 8%，字要在中間 80% 高度以內；YouTube 版避開右下角（影片長度標籤），也不要貼邊。
- 生圖品質至少 `--quality medium`（draw 預設 low，寫字很容易壞）。
- 人物、風格的規則與 A 相同（照專案文件），只是多了文字。

## 🛑 錯字檢查關卡（路線 B，不准跳過）

1. 用 Read 開**輸出後**的每一張封面，逐字比對主標原文：缺筆畫、多筆畫、漏字、多字、順序、相似字、亂碼字、多出來的雜字。
2. 有任何一處不對 → 重生（可微調 prompt，例如換更粗的字體描述、減少字數）。**最多重生 3 次。**
3. 3 次都錯 → 退回路線 A：生一張不含字的底圖，用 `--text` 疊字，並告訴使用者 B 失敗的原因。
4. **不准**交付有錯字的封面，**不准**用疊字或修圖去蓋掉錯字。
5. 交付時跟使用者說明「封面字由 AI 生成，已逐字核對」，並附上原文供對照。

## 規則

- 主標 6 字內，與 YouTube 標題呼應但不重複整句；短劇不在封面暴雷。
- 同一個頻道的封面維持同一套字型、描邊與版位，主色可依專案調整；B 是例外，用在特別企劃，不要每集都換字效。
- 輸出不帶 metadata（腳本會重建像素再存）；**原始底圖不動**。
